# XYplorer — portable panes on a morning tab desk

XYplorer keeps one named board on the desk: the live portable panes, the breadcrumb in front of you, and a short note the next person can read. Extra layouts wait for their own title.

## Session Card

| Slice | What you do in XYplorer | What remains |
|-------|------------------------|--------------|
| Arrival | Open XYplorer and name today's tab desk | A titled folder layout |
| Focus | Keep only live panes on the XYplorer board | A short breadcrumb |
| Check | Read XYplorer scripted files before a large layout change | A confirmed tab desk |
| Handoff | Mark finished tabs inside XYplorer | A note for the next person |
| Hold | Leave the layout title on the XYplorer panes | A named morning set |

## How XYplorer Sits

XYplorer does not replace a random folder jump, the unlabeled breadcrumb dump, or a script aimed at folders you do not own. It sits beside them as a named tab desk for one job: which portable panes are live, which breadcrumb still matches the scripted files you own, and what the next person should read.

Morning folders return to the same XYplorer tab desk. Extra layouts wait for their own title instead of crowding the live tabs.

A first visit should be one short breadcrumb pass on folders you own, then the same XYplorer tab desk the next day. That is enough to see if the named folder layout holds.

## Traffic Light

| Signal | On the XYplorer board | What you do |
|--------|----------------------|-------------|
| Green | Named folder layout, short live pane list | Continue the same portable panes |
| Amber | Two mornings mixed on one breadcrumb | Split the tabs before a large change |
| Red | No title, no note, scripts on folders you do not own | Stop and name the tab desk first |
| Clear | Handoff written, live tabs few | Close XYplorer and leave the tab desk |
| Hold | Breadcrumb written, panes still open | Finish the morning set, then close |

## Open Order

1. Open the last XYplorer tab desk, not a new empty folder layout.
2. Read the breadcrumb and the last handoff.
3. Finish one visible scripted-files pass inside XYplorer on folders you own.
4. Write what changed, then close with fewer random folder jumps than you found.
5. If the layout feels crowded, drop anything that belongs to a different XYplorer morning.
6. Confirm XYplorer portable panes still sit on folders you own, then leave the tab desk title on the board.

## Desk Fit

| Who | What XYplorer holds |
|-----|--------------------|
| Tab desk | Portable panes, breadcrumb, and the scripted files you own |
| Shared PC | One XYplorer profile per person |
| Support | A repeatable XYplorer layout for the same morning |
| Home | Personal folders you own, out of the work tabs |
| Review | Breadcrumb tabs kept on the same portable panes |
| Close-out | Named folder layout waiting for the last tab |

## After a Week

A week in XYplorer is not a larger pile of random folder jumps. It is the same title, a shorter live pane list, and a note that still makes sense before the next morning. Take finished tabs off the live set so the next visit starts on the tab desk that is still open.

Other programs stay where they are. XYplorer only keeps the path back: desk name, portable panes, breadcrumb, handoff.

Leave XYplorer with a quieter tab desk than the one you opened. The next visit should start on that named folder layout, not in a jump.

## Sign-off

- [ ] The XYplorer workspace name is short enough to scan
- [ ] Only folders you own sit on the portable panes
- [ ] A second person can read the breadcrumb handoff
- [ ] The last XYplorer folder layout still opens after a restart
- [ ] Finished tabs are off the live XYplorer set
- [ ] The XYplorer summary still matches the scripted files on the board

## Field Note

XYplorer is easier to trust when the tab desk stays smaller than the random-jump pile it came from. Name the folder layout, keep the live panes, finish one visible breadcrumb pass, and write what changed.

The same loop fits a morning set, a close-out, or a shared PC. Open the last XYplorer desk and continue. Do not aim scripted files at folders you do not own.

A named folder layout is enough. Do not pin every morning path you keep onto the live portable panes.
